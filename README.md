# Analisis-Perbandingan-Model-STUDI-Kasus-Naive-Bayes-Logistic-Regression-dan-Support-Vector-Machine
Analisis Perbandingan Kinerja Model Klasifikasi  STUDI Kasus Naive Bayes, Logistic Regression,  dan Support Vector Machine untuk Analisis  Sentimen Data Twitter Tagar #IndonesiaGelap
# Indonesia Gelap Sentiment Analysis

Analisis sentimen Twitter terkait isu #IndonesiaGelap menggunakan tiga algoritma Machine Learning.

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- NLTK
- Sastrawi
- Matplotlib
- Seaborn

## Dataset

Data dikumpulkan dari Twitter/X menggunakan teknik crawling.

## Preprocessing

- Case Folding
- Cleaning
- Tokenization
- Stopword Removal
- Stemming

## Models

- Naive Bayes
- Logistic Regression
- Support Vector Machine

## Results

| Model | Accuracy |
|---------|---------|
| Naive Bayes | 55,7% |
| Logistic Regression | 80% |
| SVM | 83,2% |

## Conclusion

SVM menghasilkan performa terbaik pada dataset ini.
